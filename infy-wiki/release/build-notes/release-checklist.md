# Release Checklist

Pre-submission checklist for helios° iOS and Android app store releases. Complete all items before submitting any build for review.

---

## iOS (App Store)

### App Icon

- [ ] iOS parallax icon has all 3 layers: Background (Layer 3), Helios Mark (Layer 2), Foreground Sun (Layer 1).
- [ ] Layer depths configured: Foreground 50%, Middle 33%, Background 0%.
- [ ] 1024x1024 PNG-24 exported for each layer.
- [ ] Derived icon sizes generated by Xcode (checked in asset catalog preview).
- [ ] Icon legible at all sizes: 20pt (notification), 29pt (settings), 40pt (spotlight), 60pt (home screen).
- [ ] No transparency in flattened icon; no alpha artifacts at icon edges.

### Screenshots

- [ ] iPhone 6.7" set (1290x2796): 5 scenes (Dashboard, Production, Insights, Battery, Settings).
- [ ] iPhone 6.1" set (1179x2556): 5 scenes.
- [ ] iPhone 5.5" set (1242x2208): 5 scenes.
- [ ] iPad 13" set (2048x2732): 5 scenes.
- [ ] All screenshots show dark carbon background with aurora gradient.
- [ ] All screenshots use real data values — no placeholder or lorem ipsum text.
- [ ] Status bar time is 9:41. Battery at 85%+. No carrier text.
- [ ] Screenshots are flattened PNG-24, sRGB color space, no alpha.

### Store Listing Copy

- [ ] App name: "helios° — solar intelligence" (with proper degree symbol).
- [ ] Subtitle: "Live telemetry & AI insights for your solar array".
- [ ] Promotional text: filled in.
- [ ] Full description: 3 paragraphs covering live energy, AI insights, privacy.
- [ ] Keywords: at least 20 relevant keywords, comma-separated.
- [ ] What's New: "Initial release..." text correct.
- [ ] Categories: Primary = Utilities, Secondary = Productivity.
- [ ] Supported languages: English declared.
- [ ] No emoji in any copy field.

### Privacy

- [ ] Privacy nutrition label filled: Device ID (linked), Coarse Location (linked), Crash Data (not linked).
- [ ] All unchecked data types confirmed as "Data Not Collected".
- [ ] Privacy policy URL provided and page is live.
- [ ] Privacy policy covers: no tracking, device-local data, weather API usage, snapshot sharing.

### Build & Signing

- [ ] Build number incremented (integer, higher than any previous submission).
- [ ] Version string matches semantic versioning: `1.0.0`.
- [ ] Archive signed with distribution certificate (not development).
- [ ] PrivacyInfo.xcprivacy included in target.
- [ ] Required Info.plist purpose strings included (NSLocationWhenInUseUsageDescription, at minimum).
- [ ] All required device capabilities declared (no push notifications, no HealthKit, no NFC unless actually used).
- [ ] Minimum deployment target is iOS 17.0.
- [ ] Widget extension (if included) has its own provisioning profile and signing.

### Testing

- [ ] Build uploaded to TestFlight and processing completed.
- [ ] Internal testers added and build installed by at least one tester.
- [ ] No critical crashes in TestFlight for at least 24 hours.
- [ ] All 5 tabs navigable without crashes.
- [ ] EnergyFlow renders correctly on device.
- [ ] BatteryRing renders correctly on device.
- [ ] Live telemetry data flows correctly (tested with real inverter or simulation mode).
- [ ] Weather forecast fetches correctly with both GPS and manual coordinates.

---

## Android (Google Play)

### App Icon

- [ ] Adaptive icon has foreground, background, and monochrome layers.
- [ ] All 5 density buckets generated: mdpi (108dp), hdpi (162dp), xhdpi (216dp), xxhdpi (324dp), xxxhdpi (432dp).
- [ ] HeliosMark fits within 66dp safe zone on all densities.
- [ ] Monochrome layer renders as clean white silhouette.
- [ ] Legacy 48dp icon provided for pre-API-26 devices.
- [ ] Tested on Pixel (circle mask), Samsung (squircle), and stock launcher.

### Screenshots

- [ ] Phone (1080x2400): 5 scenes (Dashboard, Production, Insights, Battery, Settings).
- [ ] Foldable (1768x2208): 5 scenes on unfolded display.
- [ ] Tablet (1600x2560): 5 scenes.
- [ ] All screenshots use Material 3 styling within Helios visual identity.
- [ ] Real data values. No placeholder copy.
- [ ] No punch-hole camera or notch emphasis in device frames.
- [ ] Flattened PNG-24, sRGB, no alpha.

### Store Listing Copy

- [ ] Short description: 80 characters or fewer.
- [ ] Full description: 3 paragraphs matching scope.
- [ ] Category: Primary = Tools, Secondary = Productivity.
- [ ] Tags: at least 5 relevant tags.
- [ ] What's New: "Initial release..." text correct.
- [ ] Feature graphic (1024x500) uploaded.
- [ ] No emoji in any copy field.

### Data Safety

- [ ] Data Safety form completed: Approximate Location (collected, not shared), Device ID (collected, not shared), Crash Logs (collected, not shared, optional).
- [ ] All other data types marked "Not Collected".
- [ ] Encryption in transit: Yes (HTTPS for Open-Meteo; local LAN traffic documented).
- [ ] Data deletion: Yes (uninstall removes all; manual reset in Settings).
- [ ] Privacy policy URL provided.

### Build & Signing

- [ ] versionCode is an integer, higher than any previous upload.
- [ ] versionName is semantic version: "1.0.0".
- [ ] Signed with upload keystore (not debug).
- [ ] Play App Signing enrolled (first upload) or using existing key.
- [ ] AAB built as `bundleRelease`, not `assembleRelease` (AAB required, not APK).
- [ ] minSdk = 26, targetSdk = 35, compileSdk = 35.
- [ ] ProGuard/R8 enabled for release (minifyEnabled = true with proper keep rules).
- [ ] No debug logging in release build.
- [ ] No test dependencies leaked into release configuration.

### Testing

- [ ] AAB uploaded to Play Console and validated.
- [ ] Internal Testing track release created.
- [ ] Testers added and at least one has installed.
- [ ] No critical crashes detected in Android Vitals for 24 hours.
- [ ] All 5 destinations navigable with predictive back gesture.
- [ ] EnergyFlow Canvas renders correctly on device.
- [ ] BatteryRing Canvas renders correctly on device.
- [ ] Live telemetry works with real inverter or simulation mode.
- [ ] Weather forecast works with both GPS and manual coordinates.
- [ ] App behaves correctly on foldable (unfolded layout switch).
- [ ] App behaves correctly on tablet (multi-column layout).

---

## Cross-Platform

- [ ] Feature parity confirmed: Dashboard, Production, Insights, Battery, Settings.
- [ ] Snapshot sharing algorithm identical across platforms (base64url, same v1 schema).
- [ ] Design tokens match between iOS and Android (colors, spacing, motion).
- [ ] Both platforms tested on real hardware (not just emulators), at least 1 device each.
- [ ] Accessibility: VoiceOver (iOS) and TalkBack (Android) basic navigation tested.
- [ ] Reduce Motion: animations disabled correctly on both platforms.
- [ ] Both apps handle network loss gracefully (simulator mode or cached forecast displayed).

---

## Final Gate

- [ ] All checklist items above are confirmed complete.
- [ ] No known critical or high-severity bugs open.
- [ ] Release notes written and reviewed.
- [ ] Privacy declarations match actual data practices.
- [ ] Screenshots reviewed on App Store Connect / Play Console preview.
- [ ] Store listing previewed and looks correct in both English (US) and any additional languages.
- [ ] Ready to submit for review.
